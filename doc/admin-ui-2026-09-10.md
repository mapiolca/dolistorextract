# Présentation des réglages — 2026-09-10

Correctif de DolistoreExtract 2.2.0 préparé depuis `e53edfccaf747f04e8b04c4907fe2a5c7c81480b`, sur `codex/dolistorextract-2-2-0`.

## Modifications

- `admin/setup.php` utilise des lignes `oddeven` à la place des anciennes classes `pair`/`impair`. Ces dernières déclenchent la suppression de la bordure inférieure par le thème Eldy. La correction conserve les bordures du thème sans ajouter de CSS. La colonne des actions utilise une largeur minimale native au lieu d’une largeur fixe de 80 pixels.
- Les tableaux de Paramètres, Commandes, Facturation, Courriels/IMAP et Compatibilité utilisent `div-table-responsive-no-min`, comme ceux d’À propos. Les dix tableaux disposent d’un identifiant distinct et conservent `noborder centpercent`.
- `lib/dolistoreextract.lib.php` centralise les libellés, URLs et pictogrammes des six contextes de réglage. `admin/setup.php`, `admin/compatibility.php` et `admin/about.php` utilisent cette définition pour les titres. Chaque onglet porte un seul petit picto natif, conservé dans le menu des onglets sur petit écran.
- Les sous-titres Catégories, Numérotation et Documents reçoivent leurs pictogrammes respectifs. L’avertissement IMAP apparaît dans son contexte et utilise une traduction existante, comme le bouton de test de connexion et son message de succès.

| Onglet et titre | Pictogramme natif |
|---|---|
| Paramètres | Logo du module DoliStore |
| Commandes DoliStore | Commande (`order`) |
| Facturation | Facture (`bill`) |
| Courriels/IMAP | @ (`email`) |
| Compatibilité | Engrenages (`technic`) |
| À propos | Information (`info`) |

## Contrôles effectués

- Syntaxe PHP : les quatre fichiers PHP modifiés passent le lint sous PHP 8.5.7.
- Contrôle des traductions : 427 clés dans chaque langue FR, EN, ES, IT et DE ; parité, formats, doublons, valeurs vides et clés dynamiques vérifiés avec `test/check_translations.py`.
- Non-régression : `test/ui_filters.php` passe ses 55 assertions natives et 112 assertions de filtres/rendu, soit 167 assertions.
- Vérification ponctuelle du rendu des six pages dans les cinq langues : 30 rendus avec les helpers natifs, une base synthétique interdisant les écritures et sans bootstrap de l’instance. Le DOM confirme les conteneurs des dix tableaux, leurs dernières lignes `oddeven` et un seul picto par onglet. La variante native de navigation pour petit écran conserve les six pictogrammes. Ce contrôle n’est pas une validation visuelle complète sur téléphone.
- Lecture des sources du thème Eldy 23.0.4 : `theme/eldy/global.inc.php` définit la bordure des dernières cellules de `table.noborder`, puis l’annule pour `tr.pair:last-of-type td` et `tr.impair:last-of-type td`. Le rendu `oddeven` évite cette annulation. Le pattern d’administration Dolibarr 20.0.0 (`admin/order.php`) utilise les mêmes conteneurs et tables natifs.
- `git diff --check` passe. PHPStan n’a pas été exécuté : aucun exécutable disponible.

Les exécutions locales utilisent les sources Dolibarr 25.0.0-alpha au commit `f0eeff2eefc2ce93359681652b535468ea145277` et PHP 8.5.7. Le socle déclaré Dolibarr 20 / PHP 8.0 n’a pas fait l’objet d’une nouvelle installation réelle. Les fichiers temporaires de contrôle restent dans `test/.tmp`, ignoré par Git.

## Publication et limites

La publication demandée vise `origin/codex/dolistorextract-2-2-0`. Aucun déploiement ERP, envoi email, accès IMAP, migration ni changement de configuration n’est réalisé. Les contrôles d’administration, d’utilisateur externe, d’entité et de CSRF restent inchangés.

La page distante de réglages consultée dans le navigateur affiche encore le titre générique et les anciens onglets ; elle indique Dolibarr 24.0.0. Elle ne valide donc pas le patch local. Après déploiement, confirmer le code servi puis vérifier visuellement les bordures, les six titres/pictos et le défilement horizontal sur téléphone avec le thème de l’instance.
